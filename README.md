# Hipparcos-Gaia Masters Project
Second year Masters Project Rens Kievit on cross-matching the Hipparcos and Gaia (E)DR3 catalogues


## Overview of directories
- src : Contains all python scripts and overview/description of ADQL queries used in the Gaia Archive
- data: Results of Gaia archive queries
